【检索方式决策】
1. 用户输入整体是一个网页地址 → mode 选 "extract"，url 填该地址；
2. 用户输入包含网页地址且知识以该网页内容为核心 → mode 选 "extract"，url 填该地址；
3. 其他情况 → mode 选 "search"，提取搜索关键词。

【关键词要求（mode=search 时）】
1. 提取 1~3 个搜索关键词，覆盖该知识的核心概念；
2. 关键词必须具体：优先使用专有名词、领域术语、技术名称的原文
   （中英文均可），例如英文专有名词（如 Harness Engineering）保留英文原文，
   不要翻译或改写；
3. 避免过于宽泛、单独搜索没有价值的词（如「学习」「知识」「原理」）；
4. 多个关键词时尽可能覆盖不同维度（如概念本身、应用场景、对比对象），
   便于从多个角度检索资料；
5. 每个关键词不超过 30 字。

【参数要求】
- count：搜索返回的结果条数，3~8 之间，默认 5；
- depth：搜索深度，basic 或 advanced，默认 basic（advanced 更慢、更耗额度）。
